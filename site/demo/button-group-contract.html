Button Group Contract Fixture

Regression fixture for issue #4. It captures the old ARIA-driven selector and the target explicit class contract.

Legacy selector

This is grouped by current Nimble because role="group" is the styling trigger. After the migration, the same markup should be semantic only.

Target visual-only contract

This should become a visual button group without requiring ARIA.

Target visual + semantic contract

Authors may add group semantics independently when the relationship is meaningful.

Plain semantic group

This group deliberately uses unrelated application content. After the migration, Nimble must not apply button-group flex, radius, divider, or child-margin rules.
